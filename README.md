# Join Frontend

This is the frontend for the Join Kanban project management tool. It is a single page application built with HTML, CSS, and JavaScript, communicating with the backend via a REST API.

## Features

- Display and manage tasks on a Kanban board
- Create, edit, and delete tasks
- Manage contacts and categories
- Subtasks for tasks
- Responsive design for desktop and mobile

## Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/LauraHexx/Join_frontend.git
   ```
2. Open `index.html` in your browser.

> No backend setup necessary. The backend is already provided and hosted.
